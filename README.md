hk-dive-visibility — Digital Clocks

This small web app displays current times for multiple time zones.

How to use

- Open index.html in any modern browser (or host via GitHub Pages).
- Use the dropdown to add time zones; click ✕ to remove a clock.
- Times update every second. State is saved in localStorage.

To publish with GitHub Pages

1. Push this repo to GitHub (already done in your repo).
2. In the repository Settings → Pages, choose Branch: main and Folder: / (root), then Save.
3. Visit the provided pages URL to see the site.
